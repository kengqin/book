# 小说书库阅读器 · Visual Studio

小说书库阅读器支持连接“小说书库”桌面端，也支持由扩展启动本地 Runtime 独立维护书架、章节和正文。不修改解决方案、项目文件或源代码。

## 核心功能

- 在“小说书库”工具窗口中浏览书籍、章节和当前五行正文。
- 在代码编辑器中使用段落模式或紧凑的行尾模式显示内容。
- 固定显示当前章序、章名和全书总进度；章节切换可使用快捷键或阅读工具窗口。
- 逐行滚动至章节边界时自动切换相邻章节，并展示新章节的多行文字。
- 鼠标悬停在小说区域时滚动切行；移出后保持代码编辑器的正常滚动。
- 支持快捷键切行、切章、切换显示模式以及显示或隐藏代码内阅读。
- 通过本机 Bridge 或 Runtime 同步书架和阅读进度，重新打开 Visual Studio 后继续阅读。
- 工具窗口提供导入、备份、恢复/迁移、重新解析、删除和 Runtime 诊断。

## 系统要求

- Visual Studio 2022 Community、Professional 或 Enterprise
- 64 位 Windows 环境
- 已安装 Visual Studio Core Editor 组件
- 桌面模式需要安装并运行“小说书库”桌面端；本地模式不需要桌面端

## 开始使用

1. 安装 VSIX，并按 Visual Studio Installer 提示完成安装。
2. 启动 Visual Studio，从“工具”菜单打开“小说书库”阅读器。
3. 默认使用桌面书库；点击工具栏的“桌面书库”切换到本地书库，并在“本地目录”中选择数据目录。
4. 本地模式首次使用时点击“导入小说”选择 TXT 或 EPUB；导入任务完成后书架会自动刷新。

可使用“备份”“恢复”在桌面书库和本地书库之间显式迁移。选择清空恢复本地书库时，Runtime 会先自动创建当前书库备份。

`工具 → 选项 → 小说书库 → 常规` 可统一配置数据源、本地目录、日志级别和是否保留受管源文件。受管源文件默认保留，关闭后可节省空间，但原文件移动后不能重新解析。

## 默认快捷键

| 功能 | Windows |
| --- | --- |
| 显示或隐藏代码内阅读 | `Ctrl+Alt+N` |
| 切换段落模式 / 行尾模式 | `Ctrl+Alt+9` |
| 上一行 / 下一行 | `Ctrl+Alt+↑` / `Ctrl+Alt+↓` |
| 上一章 / 下一章 | `Ctrl+Alt+←` / `Ctrl+Alt+→` |

在阅读工具窗口中点击“快捷键”可查看完整提示；点击“自定义快捷键”可进入 `工具 → 选项 → 环境 → 键盘`。用户自定义绑定始终优先。

## 数据与隐私

- 扩展不会直接访问或修改小说书库数据库。
- 小说正文仅作为只读的编辑器 Adornment 显示，不会写入项目文件。
- 所有书架读取与进度同步均通过回环地址上的本机 Bridge 或 Runtime 完成。
- 桌面端和本地 Runtime 都使用临时端口和令牌，不向局域网或公网开放。

## 故障排查

- 阅读器无内容：桌面模式确认桌面端正在运行；本地模式确认 Runtime 和本地目录可写，并重新打开工具窗口。
- 更换本地目录：点击工具栏“本地目录”，选择目录后会复制当前本地书库并切换。
- 安装或卸载失败：完全关闭 Visual Studio 后，在桌面端插件页面重试。
- 快捷键冲突：打开 `工具 → 选项 → 环境 → 键盘`，搜索“小说书库”命令并重新绑定。

# 小说书库阅读器 · JetBrains

小说书库阅读器支持连接“小说书库”桌面端，也支持由插件启动本地 Runtime 独立维护书架、章节和正文。插件不会修改项目文件，也不会将小说正文写入源代码。

## 核心功能

- 在“小说书库”工具窗口中选择书籍、章节并查看当前五行正文。
- 在代码编辑器中切换段落模式或紧凑的行尾模式。
- 固定展示当前章序、章名和全书总进度；章节切换可使用快捷键或阅读工具窗口。
- 滚动到章节边界时自动衔接相邻章节，一次展示新章节的多行内容。
- 鼠标悬停在阅读区域时滚动切行；移出后保留 IDE 原有的代码滚动行为。
- 通过快捷键切行、切章、切换显示模式和显示状态。
- 将书架、章节和阅读位置与当前数据源同步，重新打开 IDE 后继续上次进度。
- 工具窗口直接提供导入、备份、恢复/迁移、重新解析、删除和 Runtime 诊断。

## 兼容范围

插件面向 IntelliJ Platform 2024.1 或更高版本，可用于 IntelliJ IDEA、PyCharm、WebStorm、Android Studio、Rider、CLion、GoLand、RubyMine 等兼容 IDE。

桌面模式和独立本地 Runtime 模式当前正式支持 Windows x64；其他平台会显示明确的平台不兼容提示。

## 开始使用

1. 安装插件并重启 IDE。
2. 默认连接桌面端；在工具窗口点击“桌面书库”按钮可切换到本地书库。
3. 本地模式首次使用时导入 TXT/EPUB；导入在后台运行。点击“本地目录”可以选择目录并安全复制现有书库。
4. 从右侧工具窗口栏打开“小说书库”，选择书籍与章节。

桌面书库和本地书库可通过工具窗口的“备份”“恢复”按钮显式迁移。清空恢复本地书库前会自动生成可回退备份。

桌面端稍晚启动时，桌面模式会自动重新连接；本地模式会自动启动共享 Runtime。两种模式的数据目录互不覆盖。

`Settings / Preferences → 小说书库` 可统一配置数据源、本地目录、日志级别和是否保留受管源文件。受管源文件默认保留，关闭后可节省空间，但原文件移动后不能重新解析。

## 默认快捷键

| 功能 | Windows / Linux |
| --- | --- |
| 显示或隐藏代码内阅读 | `Ctrl+Alt+N` |
| 切换段落模式 / 行尾模式 | `Ctrl+Alt+9` |
| 上一行 / 下一行 | `Ctrl+Alt+↑` / `Ctrl+Alt+↓` |
| 上一章 / 下一章 | `Ctrl+Alt+←` / `Ctrl+Alt+→` |

在工具窗口中点击“快捷键”可查看完整提示；点击“自定义快捷键”可直接进入当前 IDE 的 Keymap 设置。用户自定义绑定始终优先。

## 数据与隐私

- 插件不直接打开或修改 SQLite 数据库。
- 小说正文仅作为只读的编辑器 Inlay 显示，不写入源文件。
- 书架与进度仅通过回环地址上的本机 Bridge 或 Runtime 交换。
- 桌面端和本地 Runtime 都使用临时端口和令牌，不向局域网或公网开放。

## 故障排查

- 工具窗口无内容：桌面模式确认桌面端已运行；本地模式确认 Runtime 和“本地目录”可写，稍候数秒等待自动连接。
- 插件更新或卸载失败：保存工作并完全关闭正在使用插件文件的 JetBrains IDE 后重试。
- 快捷键冲突：打开 `Settings / Preferences → Keymap`，搜索“小说书库”并重新绑定。

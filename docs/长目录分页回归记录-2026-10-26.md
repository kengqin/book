# 长目录分页回归记录（2026-10-26）

## 问题与原因

来源：[《公考捡漏：从女友抛弃到权利巅峰》](http://www.bookszw.com/158/158695/)。

v0.7.0 的目录发现循环把入口跳转和有效目录分页共用为最多 60 次请求。该来源每页通常展示 20 章，读到第 60 页、累计 1200 章后仍有下一页，程序直接抛出「目录超过 60 页，已停止继续解析」。整本下载会等待目录完整，因此显示「目录未完整」且正文尚未开始缓存。

## 修复

- 有效目录持续提供新增章节时，继续翻页至原站末页；60 页限制仅保留给始终找不到目录的入口跳转。
- 检测重复的分页地址、重定向回已访问的页面及整页没有新增章节，停止异常翻页并保留已识别目录。
- 支持已确认目录的末页只剩一个章节，包括没有编号的标题。
- 用独立的章节地址集合去重，允许相邻页部分重叠，保持原站章节顺序。
- 保留原有取消、限速、目录顺序校验和正文缓存机制，不改变数据库结构。

## 原站实测

使用包含修复的桌面调试构建、真实原生网络接口和隔离书库进行验证，未使用模拟网络接口或用户真实书库。

本次实测时原站共 **79 页、1574 章**，书名及作者识别为「公考捡漏：从女友抛弃到权利巅峰」「元明小阳」。

| 检查 | 结果 |
| --- | --- |
| 固定版本 v0.7.0 解析器回放同批原站 HTML | 在 60 页、1200 章处复现相同错误 |
| 修复后的桌面解析器读取真实原站 | 79 页全部读取，1574 章，目录标记完整 |
| 目录首章 | 第1章 上岸就分手 |
| 目录末章 | 第1574章 把他电话给我 |
| 首章正文 | 2716 字符，正常提取 |
| 末章正文 | 2307 字符，正常提取 |
| 原生数据库合并 | 从旧版 1200 章目录追加到完整目录，已有首章缓存保留 |

下载任务的真实「重试」操作另用旧版部分目录及一章已有缓存进行恢复验证，确认从 1200 章补齐到 1574 章后开始下载剩余正文，并可暂停；暂停时已有 2 章缓存，原有首章缓存及内容保持不变。避免重复请求缓存章节的行为另由自动测试验证。

# 界面边界复核 · 2026-10-25

针对本轮浏览器、窗口和组件交互，先用实际桌面副本复现边界问题，再修复并回放。测试使用独立数据库和屏幕之外的窗口，未操作用户实际书库。Message 保留上次恢复的外观及无阴影设置。

## 发现与修复

| 问题 | 触发方式与修复 |
| --- | --- |
| 不同浮层互相替换或清空 | Message 显示期间出现悬浮提示，Message 被替换；移开后一起消失。浮层事件现在按各自窗口订阅，Message、提示和解析弹框可同时存在并独立关闭。 |
| 浮层脱离所属窗口 | 关闭设置后 Message 残留，主窗口最小化后仍出现在桌面。现在关闭时清理浮层；最小化时隐藏，后台进度更新不重新弹出，恢复窗口后继续显示解析进度；移动窗口也同步浮层位置。 |
| 页内跳转一直加载 | 从同一网页的 `#first` 跳到 `#second` 时，不会产生新文档加载完成事件。现在识别片段跳转，保留标题和图标，避免一直显示加载中；查询参数或路径变化仍按正常导航处理。 |
| 缩窄后当前标签不可见 | 多标签窗口从 1120 像素缩到 620 像素，当前标签落在视口外。现在尺寸变化后保持当前标签可见，手动箭头和滚轮操作仍不会被状态轮询重置。 |
| 窄标签的关闭按钮挡住标题 | 极窄的非当前标签在悬浮时，关闭按钮覆盖标题点击区域。收窄状态下仅当前标签显示关闭按钮，其他标签先选择后关闭，图标和标题均可切换。 |

另将网页状态读取的标签 ID 与网页控件成对取得，避免快速切换期间把一个网页的缩放或导航状态写到另一个标签。

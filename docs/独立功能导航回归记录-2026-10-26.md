# 独立功能导航回归记录

版本：v0.7.4。基线：v0.7.3（149a833）。日期：2026-10-26。

## 修复范围

- 删除旧“工具库”首页及其卡片样式，删除笔记标题前的返回箭头和 IDE 插件页的“返回工具库”按钮。
- 笔记与 IDE 插件分别通过 `/notes`、`/ide-integration` 独立进入；侧栏维持五个固定入口，“…”保留网页浏览。
- 旧 `/tools/notes`、`/tools/ide-integration` 自动转向对应独立页面，保留查询参数与片段；旧 `/tools` 转向书架。
- 本地运行发现：编辑笔记后在自动保存延时内立即切换页面，编辑器销毁早于原有卸载保存，产生 `Cannot read properties of null (reading 'cached')`，最后修改未写入数据库。现改为路由离开前等待保存完成，失败时阻止离页；卸载保存钩子也先于编辑器销毁注册。
- 同步使用说明、架构路由清单、版本信息与更新日志。数据库 Schema 仍为 6。

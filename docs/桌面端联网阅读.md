# 桌面端联网阅读

侧栏「在线找书」支持输入书名、作者或 HTTP/HTTPS 网页地址。可在搜索框旁切换必应、百度、Google、搜狗、360 搜索、DuckDuckGo 和 Brave Search。选择结果、进入阅读器再返回时保留搜索列表与滚动位置。最近搜索支持单条删除和清空，仅保存在当前会话中；删除入口在悬停或键盘聚焦时显示。

发送用户输入的完整关键词，保留搜索引擎原有顺序，不额外排序或去重。「仅看小说」默认勾选，可取消；开启时筛选小说相关内容，关闭后显示引擎全部结果，应用会记住选择。过滤后为空时可直接选择「显示全部结果」。每页最多 10 条，通过「上一页 / 下一页」替换当前列表，已查看的页面会缓存，返回时无需重新搜索。引擎页面多出的结果暂存到下一页；必要时有限次翻页补齐，结果不足时按实际数量展示。翻页使用结果区骨架屏，分页按钮文字保持不变。列表显示本页实际数量，并非全网来源总数。

桌面端必应、Google 和 DuckDuckGo 使用渲染后的网页，以支持脚本加载并保留真实分页；必应、百度下一页地址保留关键词与分页偏移，移除会导致页码重置的会话跟踪参数。百度同时识别下一页按钮和数字页码；空分页占位符或缺少分页容器时尝试通过偏移继续请求，识别到明确末页时停止，避免反复加载末页。搜狗缺少分页信息时可通过页码继续请求，同样尊重明确末页。Google 允许跳转到官方香港域名。DuckDuckGo 可使用网页的「更多结果」继续加载，已显示的部分不会再次作为新一页展示。其余公共引擎解析返回的网页，静态页面缺少结果时尝试渲染后的页面。非桌面环境的必应网页不可用时尝试其 RSS。

公共引擎可能要求验证码或浏览器加载，应用会自动尝试使用正常浏览器会话执行脚本、保留该引擎的访问状态。仍需确认时，直接显示独立的网页窗口；用户完成确认后继续加载。窗口可随时关闭，也可取消搜索；取消翻页会保留原页。不会自动操作验证码。该浏览器会话与系统默认浏览器的登录状态相互独立，因此仍可能遇到不同的验证要求。

搜索网页返回明确的 403、404、429 或服务器错误时，会及时显示失败原因。补齐结果时遇到错误会保留已经取得的结果及重试入口。

搜索窗口仅允许加载配置的搜索引擎域名，远程网页没有本地书库接口权限；读取渲染结果通过宿主回调完成。可随时选择「在浏览器中搜索」使用系统浏览器。Brave Search 使用官方 API，需要在设置中填写密钥。密钥仅保留在当前应用会话，不写入数据库或备份。

## 阅读和导入

选择搜索结果后显示解析状态，可取消。自动寻找小说目录，识别书名、作者和章节链接。目录中间页会尝试回溯第一页，再收集分页。识别首批章节后即显示书籍预览，可立即进入阅读，后续目录在后台继续整理。返回搜索列表不会被后续目录更新重新带回预览。章节页会尝试返回完整目录；没有可靠目录时按单章处理。

章节目录只显示章节。导入前可通过书名旁的编辑入口修改书名和作者，修改结果会保留到目录整理完成并用于导入。

「开始阅读」将已识别目录加入现有书架，正文在打开章节时按需下载。目录未整理完也可阅读已识别章节，新的章节自动加入目录。「下载到书架」会等待目录完整后在后台下载全部章节，可在下载过程中阅读。中断的目录可通过下载管理继续或检查更新恢复；重新打开已有完整书籍的目录首页不会缩减其章节。正文转换为纯文本，使用现有字体、主题、隐私阅读与阅读进度功能；网页脚本和样式不会进入阅读器。

小说网站返回验证页，或直接请求遇到 403、429、503 时，会尝试独立的网页会话；需要人工验证时自动显示对应网站窗口。用户手动完成后继续读取当前页面，后续目录和章节使用同一浏览器会话。解析弹窗和主界面均提供重新打开验证窗口的入口。取消验证会停止当前解析，整本下载则暂停，避免连续弹出下一章的验证窗口；已缓存正文保留。验证页及“验证成功、正在等待响应”的过渡页不会当成正文导入。

网站验证窗口只允许原站及已配置的验证服务跳转，阻止站外广告跳转、额外弹窗和文件下载；没有本地书库接口权限。它与系统浏览器的 Cookie 独立，不会自动操作验证码，也不把浏览器 Cookie 复制给 HTTP 客户端。

## 下载任务

- 支持全部、下载中、已暂停、已完成筛选，暂停、继续、重试与取消。
- 暂停或取消后，未发出的后台请求会撤回；当前已发出的请求可能完成，不再请求后续章节或分页。未完成的分页正文不会标记为已缓存。
- 应用重新打开会恢复中断的下载，已缓存章节不会重复下载。
- 「移除任务」和「清除已完成」只移除任务记录的展示，保留书籍、正文与阅读进度，同时关闭该任务的自动追更。书籍详情的「下载管理」可重新显示任务。
- 「删除书籍」需要确认，会删除该书的本地内容、阅读进度和在线来源记录。

任务的来源、缓存状态及展示状态随完整备份保存。恢复备份后的网络任务默认暂停，自动追更默认关闭。

下载按网站分别排队：同一域名同时读取一个网页，两次请求的开始时间至少间隔 700 毫秒；网页返回后立即处理，不再额外等待。后台最多并行读取三个网站，所有请求合计最多四个，为阅读和手动解析保留容量。阅读所需章节优先于排队中的后台章节；同一章的阅读与下载共用请求，避免重复下载。已发出的请求不会被强行打断。

网页请求复用 HTTP 连接，每次建立新连接仍校验解析得到的地址，跳转也继续检查。HTTP 429、503 会让该网站单独退避，其他网站继续下载；临时网络错误保留重试。具体验证见 [下载性能优化记录](./下载性能优化记录-2026-10-23.md)。

## 更新

在线书籍详情页的阅读按钮旁可直接「检查更新」，下载任务的更多菜单中也保留入口。检查时显示加载状态，完成后原地刷新目录；有新增章节时自动开始下载。可选择自动追更。自动检查仅在应用运行时执行，间隔为 30 分钟。目录原有链接和顺序保持一致时，追加新增章节，不覆盖已缓存正文和阅读位置。目录发生删章、改链接或重新排序时停止自动合并，并显示原因。

## 解析范围

当前实现的是 HTML 的通用结构识别，无需用户编写选择器，也不要求章节名使用“第几章”格式。优先直接读取网页；受验证限制时通过独立浏览器加载，再读取渲染后的 HTML。解析器根据目录区块、重复链接结构和链接路径判断章节，保留原始标题，排除最新章节预览、推荐区和隐藏的镜像目录；同一目录下的多个分卷按页面顺序收集。标题格式仅作为缺乏结构信息时的补充线索。

目录与章节正文可以位于不同域名。跨域章节需要具有目录区块和一致的链接路径结构，零散的外站推荐链接不会因此当成目录；保存时保留原目录来源和实际章节地址。

推广页声明的章节数多于实际展示的链接时，会尝试通过公开章节的“目录”链接找到完整目录，不把短预览当成整本书。书名和作者按页面实际书籍信息识别，搜索关键词不作为书名使用。支持常见章节目录、目录分页、同一章分页、gzip/Brotli/deflate HTTP 解压、中文网页编码、重定向和代理 Fake-IP 网络；解压后的网页仍限制为 5 MB。请求按网站限速，不同网站可并行；临时网络错误会退避重试，连续失败会停止整本下载并保留失败原因。

同章分页会合并；移动站把下一章也写成“下一页”时，优先依据已识别目录区分，避免把下一章拼入当前正文。后续分页具有明确正文区且章节标题相同时，允许只有几行的短末页，避免漏掉结尾。没有目录依据且分页标题发生变化时仍停止合并。

目录也支持只有数字页码的分页及少章节分卷。脚本加载入口、动态目录和正文转码占位会尝试浏览器读取，正文占位没有结束时继续等待。分页末尾返回目录不会被当作正文续页。网站首页的推荐书单不当作一本书导入。

会员试读、明显不足的声明字数、手打中占位和私用区字体乱码不会标为已缓存。通用解析仍不能可靠判断原站所有语义错章或乱文；实际样本和限制见 [多来源小说实测记录](./多来源小说实测记录-2026-10-23.md)。

验证码需要用户手动完成。需要付费、特殊登录、浏览器不兼容的验证或特殊混淆的页面仍可能无法提取。当前没有 AI 解析服务或跨站自动换源，网页结构变化仍可能需要新增适配。

## 验证

自动测试覆盖正文清理、目录和章节分页、从目录中间页回溯、防循环、防串章、空正文、重复正文、旧库升级、缓存不被失败请求覆盖、增量更新和阅读位置、备份恢复、任务暂停恢复及移除任务保留正文。

```powershell
npm test
cargo test --offline --manifest-path apps/desktop/src-tauri/Cargo.toml --lib
cargo test --offline --manifest-path apps/desktop/src-tauri/Cargo.toml online::tests::live_public_search_and_fetch --lib -- --ignored
npm run tauri --workspace @novel-library/desktop -- build --debug --no-bundle
```

公共网络测试默认跳过，需显式运行。真实桌面测试应使用打包后的 WebView 原生接口，不能把普通浏览器中的模拟接口通过视为原生验证通过。
